# Activation Function Visualizer

I built this project to understand how activation functions work in neural networks.

In this project, I used Python, NumPy, and Matplotlib to create and plot two common activation functions:

- Sigmoid
- ReLU

I also plotted their derivatives so I could understand how they behave during training and backpropagation.

## What I did

I created input values from `-10` to `10` and passed them into:

- Sigmoid function
- ReLU function

Then I plotted:

- Sigmoid output
- ReLU output
- Sigmoid derivative
- ReLU derivative

I also printed sample values in a comparison table so I could clearly see how both functions behave for negative, zero, and positive inputs.

## Why I did this project

I did this project to understand:

- what happens to raw neuron output before activation
- how Sigmoid converts values into a range between 0 and 1
- how ReLU blocks negative values and keeps positive values
- how derivatives are used in learning

Instead of only reading formulas, I wanted to see the behavior visually.

## What I learned

From this project, I learned that:

- Sigmoid is useful when output needs to behave like a probability
- ReLU is commonly used in hidden layers
- Sigmoid becomes very flat for large values
- ReLU is simple and efficient for positive values
- derivatives are important for backpropagation
